# 이투스247 Instagram 게시물 수집기

대시보드의 인스타그램 점수 카드를 클릭했을 때 열린 공개 계정에서 최신 게시물 링크·썸네일·게시일·좋아요·댓글 수를 읽어 대시보드로 돌려보내는 Chrome/Edge 확장 프로그램입니다.

## 설치

1. Chrome에서는 `chrome://extensions`, Edge에서는 `edge://extensions`를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 `instagram-collector` 폴더를 선택합니다.

## 사용

1. 마케팅 대시보드의 SNS 분석 탭에서 지점을 선택합니다.
2. **인스타그램** 점수 카드를 클릭합니다.
3. 열린 Instagram 탭을 그대로 두면 최신 공개 게시물이 자동 수집됩니다.
4. 대시보드로 돌아오면 최신 게시물 그리드가 자동 갱신됩니다.

수집 결과는 게시일 최신순으로 정렬되며, SNS 지표 편집의 최근 30일 게시물 수와 마지막 게시일도 함께 최신화됩니다.
최근 6개 게시물의 좋아요가 모두 확인되면 평균 좋아요 기준으로 인스타 반응수 준수 점수(1~5점)도 자동 저장됩니다.

수집 토큰은 5분 동안만 유효하며, 확장 프로그램은 대시보드가 직접 연 Instagram 화면에서만 작동합니다.
